Actor Engine

A local actor-driven state plane for monitoring KoLmafia, Kingdomsitter, and KoLmafia releases while keeping execution authority outside the language clients and outside model confidence.

Source ↗Agent index ↗Back to tools
State model

Several facts can be true at once.

The Go state plane can hold ready, observe_only, kol_state_seen, kingdomsitter_seen, and release-state facts concurrently rather than compressing the runtime into one giant FSM edge.

Authority

Evidence is not permission.

Runtime observations and release metadata can shape a proposal. They do not grant permission. The implemented v0.1.0 write requires an exact state digest and human confirmation.

KoLmafia

ASH stays narrow.

kol_actor.ash publishes bounded observations to the local sidecar. Arbitrary ASH/gCLI execution, release installation/restart, and live game mutation are not implemented in v0.1.0.

Multi-language

One protocol, not seven authorities.

Go, Rust, Kotlin, C#, C++, C, and Swift clients share the versioned local protocol. Policy and execution decisions stay in the Go supervisor.
