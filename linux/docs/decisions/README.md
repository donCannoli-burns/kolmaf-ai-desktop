# Decisions — durable decision records (ADRs)

One Markdown file per decision. Filename must be the ID or ID-plus-slug:
`ADR-0001.md`. Statuses: `PROPOSED ACCEPTED SUPERSEDED REJECTED`.
`SUPERSEDED` requires `superseded_by` naming an existing decision or
architecture record.

Required front matter: `schema id kind title status owner created updated
related`. Optional: `superseded_by`.
