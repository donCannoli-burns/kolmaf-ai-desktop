Experimental · capability-first · evidence-bound

KoLmafia is the engine.

Kolmaf-AI is becoming the intelligence, evidence, instrumentation, and shared runtime layer around capabilities that already know their domains. The capability plugins are, in practice, the app. A player, deterministic dispatcher, or agent can occupy the thin dealer seat above them.

The center moved.

The old desktop/control-desk direction was useful scaffolding. The reusable thing underneath it turned out to be the seeded runtime contract inside domain capabilities.

Engine / runtime

KoLmafia stays authoritative.

Live state, requests, choices, inventory, ASH/JS, and actual game mutations remain in the runtime that already understands KoL.

Runtime seed

Capabilities gain the intelligence layer.

Typed state, WaterSheep or other learned inference, evidence, history, scoring, receipts, policy boundaries, and proof surfaces live close to the deterministic capability.

Dealer seat

The shell becomes replaceable.

A human, deterministic dispatcher, OpenCode adapter, future planner, or hybrid can call supported capabilities without reimplementing their domain mechanics.

The trust model did not move.

The architecture changed where the reusable intelligence is packaged, not who gets authority over live state.

Core invariant

Model confidence is not permission.

Learned output can rank, score, explain, and propose. Evidence can make those proposals inspectable. Neither silently becomes authority. Execution remains bounded by the capability and KoLmafia, with results bound back to the pre-action evidence whenever the integration supports it.
